---

Wrap up this session:

1. **Update `docs/STATUS.md`:**
   - tick completed checklist items (only if their tests pass);
   - set **Current step** and **Last updated** (today's date);
   - rewrite **Next action** as one sentence;
   - add to **Done so far**;
   - update **Open questions / blockers**, removing resolved ones.
2. **Append to `docs/DECISIONS.md`:** one entry per decision made this session, with date, decision, alternatives considered, reason, and a 1–3 sentence "What I should learn from this". Append only; never edit old entries.
3. **Append to `docs/JOURNAL.md`:** one section per step or sub-step finished this session, with **What** (files and behaviour), **Why** (problem and PRD requirement), **How** (approach, key code, commands), **Concepts** (the ML or engineering idea, explained as for an exam) and **Numbers** (measured results). Keep it plain-language and consistent with earlier sections.
4. Run the test suite and report the result honestly.
5. If a checklist step was completed this session, make one git commit for it (if not already committed).
6. **Explain to the user in plain English:**
   - what changed this session (files, behaviour, decisions);
   - what they should understand before the next session: the key concept or design idea, and any trade-off they should be able to justify to an examiner or interviewer.
